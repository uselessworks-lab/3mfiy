# Changelog

## Unreleased — 0.1.0

- Read and write recursive Bambu facet painting without changing mesh topology. Add bounded `BambuFacetPainting.sample` and validate nested project filament assignments. Preserve uniform face-paint compatibility.

- Declare vertex-color resources before referencing meshes so multicolor builder output passes resource-order validation.

- Builder vertex-color authoring with standard Materials corner indices; immutable, triangle-aligned Bambu unsplit face filament assignments and profile bounds checks.

- Object-oriented TypeScript document, model, resource, geometry, and transform APIs for creating and controlling 3MF files.
- Portable reading, editing, validation, and writing in Node.js, browsers, and Web Workers.
- Documented partial Core, Materials, and Production support, with explicit unsupported-markup errors.
- Optional Bambu Studio project authoring: plates, filament assignments, profiles, presets, and thumbnails.
- Git-installable repository root and a publishable `@uselessworks/3mfiy` core package.

No npm registry release has been made from this repository yet.
